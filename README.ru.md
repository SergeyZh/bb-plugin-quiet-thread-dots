# Quiet Thread Dots

Выберите для каждого треда bb, какие успешные ходы показывают точку непрочитанного. Та же настройка определяет, появится ли из-за этого треда точка на иконке bb в Dock macOS, в том числе при скрытом окне.

## Установка

```sh
bb plugin install https://github.com/SergeyZh/bb-plugin-quiet-thread-dots
```

Проверено с bb 0.50.1 и Plugin SDK 0.6.157. Плагин работает со штатной боковой панелью bb.

## Выбор режима

Откройте меню **⋯ → Unread dot** у нужного треда.

| Режим | Когда появляется точка |
| --- | --- |
| **All completions** | Действуют обычные правила bb. Это режим по умолчанию. |
| **With a final reply** | Непрочитанный ход с текстом в итоговом ответе получает точку. Успешный ход с пустым итогом проходит тихо. |
| **Hide dot** | Успешные завершения этого треда проходят тихо. |

Например, агент может следить за сборкой проекта, завершать ход молча при успехе и писать сводку при сбое. В режиме **With a final reply** сводка получит точку. Фраза «Сборка прошла» тоже считается итоговым ответом.

Фильтр сохраняет статус прочитанности в bb. Если предыдущий ответ всё ещё числится непрочитанным, его точка остаётся. Если точка уже есть при включении фильтра, плагин сразу скроет её, когда сможет подтвердить, что она относится к единственному непрочитанному успешному ходу с пустым итогом.

Ошибки и запросы, ожидающие вашего ответа, сохраняют обычные индикаторы. Другие непрочитанные треды по-прежнему дают точку в Dock, а запросы на ввод показываются числом. Push-уведомления, сортировка по прочитанности и индикаторы свёрнутых групп следуют настройкам bb. Плагин хранит на сервере bb идентификаторы выбранных тредов, режимы и время результатов.

## Разработка

Установите Node.js 24 и bb CLI, затем выполните в корне репозитория следующие команды.

```sh
npm ci
npm run typecheck
npm test
npm run build
```

Чтобы проверить локальные изменения, выполните `bb plugin install .` из того же каталога.
