---
name: quiet-thread-dots
description: "Set the unread success dot for an individual thread in bb’s built-in sidebar."
---

Use **Thread menu → Unread dot**. Choose **All completions** for bb’s default, **With a final reply** for empty successful turns to stay quiet, or **Hide dot** for all successful completions. A written “nothing to report” is a reply. An automation using the second mode should finish with empty final output on a routine batch.

The setting applies to the thread row and the unread dot in the macOS Dock. Other unread threads and pending input still contribute to the Dock badge. Push delivery, read state and group indicators follow bb’s own settings. On opt-in, a single verifiable unread silent completion is filtered immediately. Ambiguous history keeps its dot.
